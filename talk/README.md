# Präsentation

`index.html` ist die 45-Folien-Fassung des Vortrags „Die GPU kann mehr als Inferenz“. Die Datei enthält Gestaltung, Steuerung, QR-Codes, Video und Sprecheransicht bereits selbst. Sie lässt sich ohne Installation, Server oder Netzverbindung direkt im Browser öffnen.

`reserve.html` bietet dieselben 45 Folien als Bilder mit aufklappbaren Sprechernotizen. Dafür müssen `reserve.html` und `assets/folien/` zusammenbleiben.

**Bedienung:** Mit ←/→ oder der Leertaste blättern, mit `N` Notizen anzeigen, mit `S` die Sprecheransicht öffnen, mit `O` die Übersicht und mit `F` den Vollbildmodus. Externe Links zu Notebooks, Modellen und Quellen benötigen eine Internetverbindung.

Die Präsentation nutzt einen eingebetteten Offline-Player; eine separate Reveal.js-Installation ist nicht erforderlich.
